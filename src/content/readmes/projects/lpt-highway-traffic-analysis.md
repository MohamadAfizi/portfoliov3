# LPT Highway Traffic Analysis

## Overview

This data analytics project examines traffic-flow patterns at the Gombak Toll Plaza using Microsoft Excel and a custom dataset.

## Objectives

- Organize and clean the traffic dataset.
- Identify traffic-volume patterns.
- Present the findings through clear visualizations.
- Practice communicating data-driven observations.

## Tools

- Microsoft Excel
- Data Analytics
- Data Visualization
